Drawing
  • One finger scrolls. To draw, press and hold for a moment, then draw down the script. An Apple Pencil draws straight away.
  • Pinch with two fingers to zoom. The ✋ / ✏️ button makes one finger draw straight away instead (then two fingers scroll).
  • Drag down the script to draw a shot line. Hold Shift to flip On / Off Screen while drawing.
  • Tap a line to edit it. Drag its square handles to change where it starts and ends; drag the line to move it.
  • + Add Segment carries a shot on to another page. ✂ Split cuts a line in two so part of it can be off screen.
  • Leave Scene and Shot blank to have them filled in for you.
Keyboard
  • Ctrl Z undo · Ctrl ⇧ Z redo
  • O On / Off Screen · 1–8 colour
  • Delete delete the selected line · E add a segment
  • + − zoom · 0 fit to width · F focus mode · Esc close
